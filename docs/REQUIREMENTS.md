# 要件と施主の決定 — NeNe Poker

> Status: normative（規範）/ 2026-10-26 初版
> 施主（hide）が言ったこと・決めたことだけを書く。**施主が言っていない機能を要件に書かない・実装しない。**
> 施主から後で違う指示が来たら、それに従って変え、ADR で置き換える。

NeNe Poker は、WSL2 の Ubuntu の端末（Windows Terminal）で、手作りの AI 4 人が自動でノーリミット・テキサスホールデムを打ち続けるスクリーンセーバーである（Swift 製）。
1 卓が終わったら次の卓を始め、`q` を押すまで続く。施主の言葉は「ポーカーをやりたい。親と子で四人。メインの子を擬似プレイヤーにしてプレイヤーの札は基本見える。
全員見えるモードとプレイヤー以外見えないをキーでトグル。あとは gambit 系の作り方を踏襲して」。
チェス版の [NeNe Gambit](https://github.com/hideyukiMORI/nene-gambit)・リバーシ版の [NeNe Reversi](https://github.com/hideyukiMORI/nene-reversi)・
囲碁版の [NeNe Igo](https://github.com/hideyukiMORI/nene-igo) と同じ形（サイバー HUD・12 テーマ・4 名のキャストの減らず口・結果の後の秒読み・`install.sh` の 1 行で入る配布）を、
ポーカーで、新しいキャストで作る。スクリーンセーバーに要るのは強さではなく「見ていて飽きない卓」である。チップは架空の点数で、現金とは関係が無い。

## 1. 要件（FR）

FR の番号は兄弟とそろえた。

| ID | 要件 |
| --- | --- |
| FR-01 | 端末にポーカー卓を描き、4 人が 1 行動ずつ打つ様子を見せる。**卓に 4 人・親（ディーラーボタン）はハンドごとに左へ回る** |
| FR-02 | **ノーリミット・テキサスホールデム**のルールを完全に扱う: ブラインド・4 つのベッティングラウンド（プリフロップ・フロップ・ターン・リバー）・フォールド/チェック/コール/ベット/レイズ/オールイン・最小レイズ額・**サイドポット**・ショーダウン・**スプリット**（割り切れないチップの扱いを含む）・ヘッズアップ（残り 2 人）の親とブラインドの決まり。出典（一般に使われるルールの文書）を ADR に書く |
| FR-02a | **役判定**は 7 枚から最良の 5 枚を選ぶ。正しさは公表値との一致でゲートに入れる |
| FR-03 | AI は**自前の勝率の見積もり（場札と相手の手札を乱数で埋めるモンテカルロ。回数で打ち切る）＋ポットオッズ＋性格**で行動を選ぶ |
| FR-04 | **卓の終わり**: チップが 0 になった人は抜け、**最後の 1 人が全チップを取ったら優勝**。結果を見せ、全員のチップを初期額に戻して**次の卓を自動で始める**。1 卓が終わる長さに収まるよう**ブラインドは段階的に上がる**（上がり方は計測して ADR） |
| FR-05 | **毎回違う展開**（シャッフル・同点の行動の乱数・ブラフの乱数）。同じシードなら同じ展開 |
| FR-06 | 4 人で性格を変える（手の選び方の緩さ・攻撃性・ブラフの頻度・勝率の見積もりの回数）。勝ち負けにばらつきを出す |
| FR-07 | **メインの子（擬似プレイヤー）**: 4 人のうち 1 人を卓ごとに乱数で選び、画面の手前（南）の席に座らせる。メインの子も AI が打つ。**メインの子の札は常に表** |
| FR-07a | **表示の切り替え**: キー `v` で「**プレイヤー以外伏せる**（VIEW: YOU・既定）」と「**全員見える**（VIEW: ALL）」をトグル。起動時は `--view you|all`。切り替えは**表示だけ**で、対局の進み方・乱数・セリフは変わらない。ショーダウンに残った人の札はルールどおりどちらのモードでも表 |
| FR-07b | 札は**文字の字形ではなく、札の地の色で塗った偶数桁のブロックに ASCII のランクとスート（`A K Q J T 9…2`・`s h d c`）**で描く。スート記号 `♠♥♦♣` は使わない。4 色のデッキ |
| FR-08 | `q` で終了する。どんな終わり方でも端末を必ず元に戻す |
| FR-09 | 動作環境: WSL2 の Ubuntu＋Windows Terminal |
| FR-10 | HUD に MATCH（卓・ハンド・ブラインドと段階・親）・STACKS（4 席のチップ）・LOG（行動の履歴）・RESULT（勝者・役・額）。メインの子の札の横に今の役の名前。**勝率や推奨手は出さない** |
| FR-11 | 1 行動の間隔の初期値は 1.0 秒・ハンド/卓の結果を見せる時間の初期値は 3 秒。起動オプションで変えられる（兄弟の値） |
| FR-12 | 12 テーマは兄弟の 12 種類を引き継ぎ、卓・札・スート 4 色・札の裏の色を足す |
| FR-13 | 実行中のキー `t` でテーマを切り替え、起動時は `--theme <名前>` |
| FR-14 | 各キャラクターが感想やリアクションを言う。英語で、ウィットに富んだブラック、ニヤッとしてしまうもの。キャストは 4 名。セリフは 1 人 50 本。**キャストは Gambit・Reversi・Igo とは別の新しい 4 名** |
| FR-15 | キーのヘルプを画面に常に出す（`q` `t` `v`） |
| FR-16 | 画面は兄弟の B 案と同じ構成（罫線の枠・2 段の配置・結果の後の秒読み・罫線が 2 桁で描かれる端末では ASCII の枠） |

## 2. 施主の決定（2026-10-26）

| # | 論点 | 状態 |
| --- | --- | --- |
| Q1 | アプリ名 | 決定: NeNe Poker（`nene-poker`） |
| Q2 | 公開範囲とライセンス | 決定: PUBLIC・MIT |
| Q3 | ポーカーの種類 | 決定: テキサスホールデム（ノーリミット） |
| Q4 | 人数と親 | 決定: 卓に 4 人・親（ディーラーボタン）は回る。そのうち 1 人がメインの子（擬似プレイヤー） |
| Q5 | 札の見え方 | 決定: メインの子の札は常に表。「全員見える」と「プレイヤー以外伏せる」をキー `v` でトグル。**既定は「プレイヤー以外伏せる」（VIEW: YOU）**（施主が 2026-10-26 に確認） |
| Q6 | 終わり方 | 決定: 最後の 1 人まで → 全員のチップを戻して次の卓 |
| Q7 | キャスト 4 名 | 決定（推し）: 実装側が決める。兄弟 3 作のキャスト（Gambit: VEX.EXE / MORT.SH / NULL_PTR / GRANNY.DLL、Reversi: FLIP.BAT / CORNER.SYS / SPAM.EML / LAZY.CRON、Igo: SENTE.SYS / TENUKI.LOG / MOYO.PNG / SEKI.LCK）と違う名前・性格にし、`ファイル名.拡張子` 風の名前と顔文字の作法はそろえる。性格の違いと勝ち負けのばらつきは計測して ADR に書き、施主に知らせる |
| Q8 | 画面 | 決定: 兄弟の作り方を踏襲する。席の配置（メインの子は南・ほかは西・北・東）・札の描き方（ASCII と 4 色）・2 段の配置は施主の指定で作った画面仕様に従う |
| Q9 | 道具・進め方 | 決定（兄弟と同じ）: 開発用の道具は確認なしで入れてよい。フルゲートが緑なら Ready・squash merge・Issue の起票は確認なしでよい。**Release の公開など外に出る操作は施主の確認を取る** |
| Q10 | v0.1.0 の公開 | 決定（2026-10-26）: 施主が公開を承認し（「許可。それでいい」）、施主自身が `gh release create v0.1.0` を実行して公開した（main `d9a4fb1`・成果物の SHA-256 `5a4014b44383449db05640151be9a37663f6d536b21c5a22988cad9394814f18`）。以後の版の公開は Q9 のとおり確認を取る |
| Q11 | PowerShell 用のワンライナー | 決定（2026-10-26）: 施主の依頼「PowerShell 用のワンライナーも書いておいて。nene-wire がやってるのを参考にして」。`install.ps1`（`irm … | iex`）で WSL の中に入れ、PowerShell と cmd から起動できるようにする（ADR 0014） |

## 3. やらないこと

- 施主が言っていない機能（人間が操作して打つ機能・賭け金の入力・勝率や推奨手の表示・トーナメント表・ほかのポーカーの種類を含む）
- 外部のポーカーエンジン・役判定のライブラリを使うこと
- 実在のカジノ・ポーカーサイト・ブランドの名前やロゴを書くこと。賭博を勧める文言（現金・入金・オンラインカジノへの誘導）を書くこと
- 公表値（役の種類ごとの数）を記憶で書くこと・ゲートで回す件数を黙って下げること
